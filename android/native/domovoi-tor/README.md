# libdomovoi_tor.so: away chat's Tor

Built from the repository's [`native/domovoi-tor`](../../../native/domovoi-tor/)
crate (Arti, MIT OR Apache-2.0) by its `build-android.sh`; the crate's
README says what it is and how to rebuild. `jniLibs/<abi>/` is what the app's
Gradle build packages, `SHA256SUMS` their hashes (`NativeTorLibraryTest`
holds the files to them), `BUILD-INFO.txt` what built them.
