Domovoi

Domovoi is your home's own computer system: music, files, rooms, voice and optional AI, all kept at home.

This package puts the Domovoi app in Applications and Domovoi's tools in /Library/Application Support/Domovoi. Nothing else changes yet.

When it finishes, open the Domovoi app from Applications. It checks this Mac, lists every change it would make, and asks two questions. Only when you choose Install there does it change this Mac, after asking for an administrator's password once.

Domovoi needs a Mac with Apple Silicon, macOS 26 or later, 16 GB of memory and about 50 GB of free space.
