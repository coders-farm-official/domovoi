# Domovoi 1.2.1

**The home computer system that just works. Keeps it in the house.**

Domovoi turns a computer you already own into your home's own system: your
music, movies, audiobooks, files and documents in one place, playing in every
room and on your phone. No cloud, no subscription, and nothing leaves your
network unless you say so.

This release follows 1.2.0 and is a fix release for the server and Windows:
song recognition that stops renaming songs wrongly, a Windows update that
finishes what it starts and says what it did, rooms that wake less on the
TV, and wake words you can download and share. **The Android app is not
part of it:** it stays 1.2.0, and phones get nothing new. If this is your
first look, start with the
[README](https://github.com/coders-farm-official/domovoi#readme).

## What is new since 1.2.0

### Song recognition gets your songs right

- **No more covers, instrumentals or remixes.** When a song already names
  a real artist, a recognition answer must be by that artist; a matching
  title alone is no longer enough. Answers that add "instrumental",
  "karaoke", "cover", "remix" or "tribute" are refused, so "Jumper" by
  Third Eye Blind stays Third Eye Blind.
- **Upload-style names are understood.** Files named like a video upload
  ("That's what I like (Lyrics)", a channel as the artist, "Official",
  "HD") are matched to the right song instead of being put back to the
  upload's names. A matched title drops the upload words.
- **A repair for libraries it damaged** (see Upgrading): it finds the songs
  an earlier run renamed and puts the file's own names back, and songs it
  set aside can be looked up again under the new rule.

### Updating Domovoi on Windows

- **The tray's Update Domovoi finishes the job.** After the Linux part, the
  icon checks again and goes on to the Windows part when the new code
  needs it, and it reports what really ran. The dashboard no longer shows
  a Linux-only update as "the Windows side updated".
- **One button at a time** on the Version card (Settings, System, About &
  updates): **Update Domovoi** while the Windows part is needed, **Try
  again** after a failed step, **Check for updates** only when nothing is
  pending.
- **An update asked for from a phone stays in sight on the PC.** The icon
  beside the clock wears a blue **!** until someone clicks it, and the
  notification comes back (after 5, 15, 30 and 60 minutes, then hourly,
  and when someone returns to the PC) instead of vanishing after 30
  seconds. The card says when it was asked, whether the PC has seen it,
  and has **Cancel request**.

### Rooms wake less on the TV

- **New defaults: Wake sensitivity 0.7 and Wake confirmation 2** on a Pi, a
  PC room and a phone in room mode. Tried in a real house, rooms woke less
  on the TV and phones and still heard the word.
- **A newly trained wake word starts at 0.7** too, so pushing it to a room
  no longer loosens the room back to 0.5. Words you already made keep
  their value.

### Share a wake word you trained

- **Download** on a ready word (Settings, Voice, Wake words) gives a zip
  with the model, its checksums, a model card filled from what the server
  recorded, and a licence notice. No recordings, rooms or paths go in.
- **Sharing:** a word trained at home may be shared non-commercially under
  CC BY-NC-SA 4.0 with the notice in the zip. One trained on your
  household's voices is your call to share; **Synthetic voices only**
  carries nobody's voice.

### Also

- **Speech recognition can't hang on music.** Music could send the speech
  model round the same few seconds of audio forever, so a room stopped
  answering until a restart. That fix was already in 1.2.0's code but
  missing from its notes.
- **The guides were brought up to date** with the code: the user guides,
  the manual, the host and device guides, licences, privacy and the API
  reference.
- **Releases are now numbered by Domovoi's own version.** The Android app
  keeps its own number and is released only when it changes; this release
  doesn't change it, so it stays 1.2.0 on Google Play and on the v1.2.0
  release, where your server keeps fetching it from.

## Known limits

- **Pi and PC rooms keep a Wake sensitivity of 0.5** until you change it:
  their setup wrote 0.5 into their settings. Set it to 0.7 in the room's
  Settings tab if you want the new default. If a room now misses you
  across the room, set its Wake confirmation back to 1.
- **The Windows installer and the Windows room Setup are not code-signed.**
  Windows SmartScreen will ask before running them.
- **No encryption on your home network.** Domovoi uses plain HTTP inside the
  house and has one shared household key, plus one admin password. It is not
  meant to be reachable from the internet, so do not port-forward its ports.
  The [security notes](https://github.com/coders-farm-official/domovoi/blob/main/docs/SECURITY_PRIVACY.md)
  say plainly what it does and does not guard.

## Upgrading

- **Linux servers:** Settings, System, About & updates, **Update Domovoi**.
  There are no database changes, and it rolls back by itself if the new
  code does not come up healthy.
- **Windows installs:** use the dashboard's **Update Domovoi** on the
  Version card (Settings, System, About & updates); it updates both
  halves. The tray fixes arrive with the Windows part itself, so on a PC
  whose icon is still 1.2.0, start the Windows part from the Version card
  or from the icon's **Finish updating Domovoi...**, not from the old
  icon's own **Update Domovoi**.
- **Rooms:** **Upgrade room** on the dashboard gives a room that never set
  Wake confirmation the new 2. Wake sensitivity is set in each room's
  Settings tab.
- **Songs renamed by song recognition:** an admin runs the repair once,
  `POST /api/music/library/enrich/repair` with the admin token and no body.
  To look the songs it set aside up again, run it once more with
  `{"requeue_disagreed": {"since": "<start>", "until": "<end>"}}`, a window
  around the repair's run (the core log's "library enricher repair" lines
  give the times). Songs you edited by hand are never touched.
- **Scripts:** a Windows install's version answer marks what the tray ran
  (`kind`: `windows` or `linux`) and when the PC saw a request (`seen_at`);
  new: `GET /api/wake-words/{id}/export`
  ([API reference](https://github.com/coders-farm-official/domovoi/blob/main/docs/API_REFERENCE.md)).
- **Android:** nothing to do. The app stays 1.2.0, from Google Play or from
  your server's **Download the app to this server**.
