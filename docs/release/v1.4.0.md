# Domovoi 1.4.0

**The home computer system that just works. Keeps it in the house.**

Domovoi turns a computer you already own into your home's own system: your
music, movies, audiobooks, files and documents in one place, playing in every
room and on your phone. No cloud, no subscription, and nothing leaves your
network unless you say so.

This release follows 1.3.0. Your house can now make friends with other
Domovoi houses (off until an admin turns it on), chat can watch a short
video, a scanned letter can be read back to you, a room can wake on more
than one word, and the dashboard opens at plain `domovoi.local`. A phone in
room mode shows what its room is doing, radio understands station names the
way people say them, and an admin who walks away is signed out after an
hour. If this is your first look, start with the
[README](https://github.com/coders-farm-official/domovoi#readme).

## At a glance

- **Friend Houses:** "Serverless messaging and friend system between households". Become friends with other Domovoi houses, send messages and share lists, house to house, with no server in between. Off until an admin turns it on. ([How it works](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/docs/SECURITY_PRIVACY.md#friend-houses-house-to-house-off-by-default))
- **Videos in chat:** attach a video of up to 3 minutes to a home-server chat, and Domovoi watches it and answers questions about it. ([Manual](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/scripts/manual/manual.md#ask-about-a-video))
- **"What does it say?"** A scanned letter is read on your server, summed up in plain words, and read aloud if you ask. ([Manual](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/scripts/manual/manual.md#what-does-this-scan-say))
- **Up to five wake words per room,** and "Domovoi" tuned to your own household's voices. ([Manual](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/scripts/manual/manual.md#wake-word-and-greeting))
- **A phone in room mode shows the room:** what is playing, with pause and skip, and its timers and alarms counting down. ([Room mode](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/docs/SPARE_DEVICE_SATELLITES.md#phones-and-tablets-room-mode))
- **Radio by how it's said:** "lo-fi 24 slash 7" finds "Lofi 24/7", search goes past your favorites, "add this to my favorites", and any station plays in a room. ([Manual](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/scripts/manual/manual.md#radio-plugin))
- **Just type `domovoi.local`:** the dashboard opens without `:6369`, and its header shows the address to give someone else. ([Manual](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/scripts/manual/manual.md#start-here))
- **Queue history, and documents as Word or PDF:** see what Up next picked and why, and download a document as a Word file or a PDF. ([Up next](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/scripts/manual/manual.md#up-next), [Documents](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/scripts/manual/manual.md#documents-and-spreadsheets))

### Also in this release

- **Admins are signed out after 1 hour idle:** an hour with no change made as admin.
- **A new room asks every Domovoi server it finds** and joins only the one where you typed its code, which the room can check for itself.
- **The Windows tray can't get stuck** offering an old Setup after one that didn't finish.
- **Printing:** network printers only, said where you add one; the server itself can't be added as a printer.
- **Fixes from a round of testing:** a deleted song stops playing, an offline room no longer looks like it is playing, Health updates on its own, and rooms recover their Wi-Fi and missing packages better.
- **Plugins** can speak in a room's voice, understand spoken names and choices, and hold a live connection with phones and browsers.
- **Fewer "preview" labels:** only the USB stick for old computers is still a preview.

### Security fixes

- **The household key is blanked whole in the log:** before, a key starting with certain punctuation could reach the server's log in part.
- **Printers can't point back at the server:** printing and scanning refuse the server's own addresses, whatever the outbound allow-list says.
- **setuptools** (the Linux server's build tool): moved past two published advisories.

### Upgrading

- **Update as usual:** Settings → System → About & updates → **Update Domovoi**. The eight database changes run by themselves. Windows: finish the Windows part from the Version card or the tray icon.
- **Admins:** a signed-in dashboard drops to signed out after an hour with no admin change.
- **Linux, a dashboard unit you manage yourself:** it needs the low-port permission for the short address ([how](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/docs/LINUX_HOST.md#sandboxing-the-units)).
- **Internet set to No:** install the scan reader by hand (`tesseract-ocr tesseract-ocr-eng`).
- **Plugin authors:** a plugin websocket needs SDK 1.11, so update Domovoi before installing a plugin that uses one.
- **Rooms:** **Upgrade** a room to give it more wake words and the room fixes.

### Known limits

- **Friend Houses has one inbox per house,** and encryption is between houses, not between people. It needs the internet.
- **Scans are read in English only.** One scan or video at a time, at the lowest priority.
- **A new room with no server address typed** doesn't ask a server older than this release.
- **The Windows Setups are not code-signed,** and Domovoi uses plain HTTP inside the house: don't open its ports to the internet.

## What is new since 1.3.0

### Friend Houses

"Serverless messaging and friend system between households". It is **off**
until an admin turns it on in **Settings → Household → Friend Houses**.
While it's off, nothing runs and nothing connects.

- **Becoming friends.** An admin makes a **friend file** (one line, valid
  for 1 to 30 days) and sends it to the other house however you like. The
  other house's admin uses it to ask, and nothing happens until an admin
  here accepts. Both houses then show the same 4-digit code: compare it by
  phone or in person to mark the friend verified. Every new friend is
  announced aloud in the rooms, so nobody can be added quietly.
- **Messages.** The house has one inbox. Each friend's messages can stay in
  the inbox (the default), be announced with who it's from, or be read
  aloud; quiet hours stay quiet. A message waits until the friend's
  house confirms it has it, and shows "Not delivered" after a week. A
  conversation can be exported, and stays readable after a friend is
  removed.
- **Shared lists.** Share a household list with a friend house: each house
  keeps its own copy and the two keep each other up to date. A list a
  friend offers waits for an admin to accept it. Either house can stop
  sharing at any time and both keep their copy.
- **Household phones.** With the household key, phones can read the house
  inbox, send messages and see the friend list and shared lists, with the
  friends the house already has. Adding, removing, verifying and sharing
  stay with an admin. The phone apps use this once they are updated.
- **No server in between.** Houses reach each other over the Tor network,
  each through a Tor service that only its friends can find, so neither
  house learns the other's address and no Coders Farm server is involved.
  Every connection is also checked against the current friend list, and
  every message is signed by the house that sent it.
- **Fenced off from your home.** The Tor part runs in its own container, and
  the installer's firewall rules keep that container away from the server's
  own services and the rest of your home network. The Friend Houses page
  warns while those rules are missing. Setting the internet to No stops it.
  Where using Tor is restricted, leave it off.

[How it works, and what it does and doesn't protect](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/docs/SECURITY_PRIVACY.md#friend-houses-house-to-house-off-by-default)
· [The firewall](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/docs/LINUX_HOST.md#friend-houses-firewall)

### Chat watches a video, and reads your letters

- **Videos in chat.** Attach one short video to a home-server chat with the
  paperclip: MP4, MOV or WebM, up to 3 minutes and about 2 GB. Domovoi
  watches it in the background ("Watching your video… about 4 minutes
  left", with stop) while you keep chatting, then writes a short summary
  and answers questions from what was said and a few frames, always worded
  as what a frame "might show". The video and its frame grabs are deleted
  as soon as it has been watched; only the text stays, with the chat. It
  uses the models you already have, and is hidden when AI features are
  off. The phone apps offer it too, with the updated apps.
  ([Manual](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/scripts/manual/manual.md#ask-about-a-video))
- **"What does it say?"** A scan saved to Documents is now read on your
  server. Printed words are read directly (OCR); a page it can't read well,
  such as handwriting or a photo, goes to the picture model, and Domovoi
  says what it "might say". Press **What does it say?** for a short plain
  summary and the full text, or say "scan this letter" and answer yes when
  Domovoi offers to tell you what it says. A read scan works like any
  document: ask about it, or say "read me". With AI features off, printed
  pages are still read, without the summary. The phone apps show the
  button with the updated apps.
  ([Manual](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/scripts/manual/manual.md#what-does-this-scan-say))
- **Voice comes first.** Watching a video and reading a scan pause from a
  room's wake word until the answer has been spoken.

### Rooms and wake words

- **Up to five wake words per room.** On a room's **Overview** tab, an admin
  can **Add another wake word**, put the words in order and **Save**. A
  Raspberry Pi Zero 2 W runs three, a bigger Pi or a spare PC five, and a
  phone in room mode says what it can. Each extra word makes waking by
  mistake a little more likely, and the room's history names the word that
  woke it, so a false wake's culprit shows.
  ([Manual](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/scripts/manual/manual.md#wake-word-and-greeting))
- **Tune Domovoi to your household.** In **Settings → Voice → Wake words**,
  record a few clips of everyone saying "Domovoi", then train: the server
  makes your household's own copy of the "Domovoi" word, and your rooms
  switch to it. The recordings and the tuned word stay on your server.
  **Go back to the standard Domovoi word** undoes it everywhere. It needs
  wake-word training turned on.
  ([How](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/scripts/wake_word/README.md#tune-domovoi-to-your-household))
- **A phone in room mode shows the room.** Its screen shows what the room is
  playing, with pause, skip and back, and the room's timers and alarms
  counting down, with stop when one goes off. Reminders never show: anyone
  in the room can read the screen. With the updated apps.
  ([Room mode](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/docs/SPARE_DEVICE_SATELLITES.md#phones-and-tablets-room-mode))
- **"Stop" stops the alarm first.** While a timer or an alarm is going off,
  "stop" silences it and leaves the music playing; the next "stop" stops
  the music. "Stop the timer" also stops an alarm that is going off.
- **A new room asks every house.** A room set up from its Wi-Fi page with
  the server address left blank used to wait on whichever Domovoi server
  answered first; on a network with two servers it could wait for ever on
  the wrong one. It now asks every Domovoi server it finds and joins only
  the one that proves it knows the room's six-digit code: the one where you
  typed it. The room never sends its code anywhere, and once one server
  approves it, it withdraws from the others. After you type the code, the
  room appears within about ten seconds.
  ([How it works](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/docs/SECURITY_PRIVACY.md#asking-every-house-an-approval-the-device-can-check-140))
- **Fewer "preview" labels.** Chat on the phone itself, the Windows
  installer and spare laptops, PCs and phones as rooms are no longer
  labelled previews. The USB stick for old computers still is: it has not
  been tried on enough real computers yet.

### Music and radio

- **Queue history.** **Settings → Household → Queue history** (admin)
  lists every Up next session with the songs it picked, in order, and why
  each one, and downloads a session's picks. It only reads; an ended
  session is deleted after 30 days.
  ([Manual](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/scripts/manual/manual.md#up-next))
- **Radio finds stations by how they are said.** "lo-fi 24 slash 7" plays a
  favorite called "Lofi 24/7", and a near miss is asked about ("Did you
  mean Lofi 24/7?"). Past your favorites it looks at the other saved
  stations, then, with the internet allowed, the station directory. "Add
  this to my favorites" stars the station playing, and a station can be
  played in a room from the Stations page or cast there from the player.
  ([Manual](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/scripts/manual/manual.md#radio-plugin))
- **A deleted song stops being played.** Taking a song out of the library
  while it plays moves every room on to the next song (or stops it), and
  removes the song from every queue.

### Files and printing

- **Download as Word or PDF.** In Files → Documents, **Download** on a
  document made in Domovoi's editor offers **Word (.docx)**, **PDF** or
  **Web page**. Before, it saved the stored page, which looked like a
  broken download. **Download as zip** puts such documents in as Word files
  too. Pasting or dropping a picture into the editor puts it at the
  cursor. The phone apps save Word files too, with the updated apps.
  ([Manual](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/scripts/manual/manual.md#documents-and-spreadsheets))
- **Network printers only, said where it matters.** Domovoi has always
  printed to Wi-Fi and network printers only. That is now said where you
  add a printer, when a typed address isn't a printer, and when "set up the
  printer" finds none. The server's own addresses are always refused.
  ([Manual](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/scripts/manual/manual.md#printers-and-scanners))

### The dashboard

- **The short address.** Type `domovoi.local` (or the server's address) and
  the dashboard opens, with no `:6369`. The dashboard also listens on the
  usual web port and only sends you on to the dashboard; nothing else is
  served there. It is on only when nothing else on the server uses that
  port, and an admin can switch it off in **Settings → System → Advanced →
  Short address**. Links, rooms, the apps and bookmarks are unchanged.
  ([Manual](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/scripts/manual/manual.md#start-here),
  [what it does](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/docs/SECURITY_PRIVACY.md#the-short-address-port-80-a-redirect-and-nothing-else))
- **An address to share.** The header shows the easiest address to give
  someone else; click it to copy it.
- **Admin signs out after 1 hour idle.** A tab left open overnight was
  still admin in the morning. Now an hour with no change made as admin
  signs it out, and the tab says so. Pages that refresh themselves don't
  count. A reload within the hour keeps you signed in, and **Stay signed in
  after a reload** now goes up to 60 minutes.
  ([Manual](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/scripts/manual/manual.md#guests-household-and-admin),
  [details](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/docs/SECURITY_PRIVACY.md#signing-out-after-an-hour-idle))
- **An offline room no longer looks like it's playing.** Settings →
  Household → Rooms says the room is offline and its music isn't reaching
  it, instead of a progress bar counting on.
- **Health updates on its own,** every ten seconds and when you come back
  to the page, so a switch to the backup speech model shows without a
  reload.
- **A plainer Models page,** worded for households.

### Fixes from a round of testing

- **The waking-up line** ("Just a moment, I'm waking up my language
  model.") is listed in the room's history, and only said when the model
  still isn't ready after a second and a half.
- **A room device that can't install its system packages says why,** on its
  card and in its log, and repairs half-installed packages the way setup
  does. The card no longer promises that a reboot fixes it.
- **Wi-Fi recovery fits the room's network,** so a room whose Wi-Fi dropped
  comes back without waiting for its watchdog restart.
- **A song whose file is gone** says "That song isn't in the library any
  more." instead of an internal error.

Rooms get the room fixes with their next code upgrade.

### Windows

- **The tray can't get stuck on an old Setup.** After a Setup that didn't
  finish, the tray's **Update Domovoi** could download a Setup it then
  refused every time, and the server wasn't updated either. The tray now
  never downloads a Setup that isn't newer than itself, and a Setup that
  didn't finish says so in the tray menu and on the dashboard's Version
  card. A newer Setup run over an install updates the Windows side only,
  and its last page says the server updates through **Update Domovoi**.
  ([Windows guide](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/docs/WINDOWS_HOST.md#when-something-goes-wrong))

### For plugin authors

- **Speech in a room's voice (SDK 1.9).** `sdk.speech.render` turns text into
  speech in the voice a room's replies use, without playing it, and a
  plugin can read which model the house uses for questions.
- **Spoken names and choices (SDK 1.10).** Helpers for matching names the
  way people say them, and for asking "did you mean…?" and handling the
  answer; a plugin's player source can play in a room. The bundled Radio
  plugin needs this.
- **Live connections (SDK 1.11).** A plugin can hold a websocket open with
  the household's phones and browsers, for a game or a remote control. It
  needs the household key or an admin sign-in, is checked again every 30
  seconds, and is capped in number, size and rate. The install screen
  lists each one.

[Plugin development guide](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/docs/PLUGIN_DEVELOPMENT.md#4-the-sdk-tour)

### Documentation and how Domovoi is made

- **The docs were gone through end to end:** the README's front door, the
  FAQ, the glossary, the host and room guides, the manual and the help
  desk now match what the code does, and the developer docs lost their
  stale history.
- **Release pages open with Download:** the files and how to install come
  first, then what's new, with a link to these full notes.
  ([The release page](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/docs/CONTRIBUTING.md#the-release-page))
- **Every change now reaches the main branch through a pull request** that
  merges itself once the full test run passes.
  ([Pull requests](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/docs/CONTRIBUTING.md#pull-requests))

## Security fixes

- **The household key is blanked in the log, whole.** The server's log
  blanks the key in a connection's address (`?token=`). A key starting with
  certain punctuation could reach the log in part; now the whole value is
  blanked, for every connection, whatever characters the key holds.
- **Printers can't point back at the server.** An admin could add a
  "printer" on the server's own loopback by listing it in
  `OUTBOUND_ALLOW_HOSTS`. Printing and scanning now refuse loopback,
  `0.0.0.0` and every address the server holds, whatever that setting
  says. It still allows a printer on another private subnet.
- **Admin sign-ins end after an hour idle,** so a dashboard left open
  doesn't stay admin (see The dashboard, above).
- **setuptools** (the build tool the Linux server's packages are installed
  with) moves past two published advisories,
  [GHSA-h35f-9h28-mq5c](https://github.com/advisories/GHSA-h35f-9h28-mq5c)
  and [GHSA-xmj3-9gf7-h52w](https://github.com/advisories/GHSA-xmj3-9gf7-h52w).
- **The new features were reviewed before release.** The every-house room
  approval was hardened after a security audit: a server can no longer
  freeze a new room by keeping its connection busy, a room limits how many
  codes it will check, and the "can this server prove an approval" answer
  is signed. Friend Houses' Tor container is firewalled off from the house
  (above).

## Upgrading

- **Update Domovoi:** Settings → System → About & updates → **Update
  Domovoi**. The update rolls back if the new code doesn't come up healthy.
- **Database changes run by themselves.** Eight of them, V062 to V069: room
  approvals that can be checked (V062), several wake words per room (V063),
  videos in chat (V064), read scans (V065) and Friend Houses (V066 to
  V069). Nothing to do.
- **Windows installs:** **Update Domovoi** does the Linux part first, then
  asks for the Windows part, which comes from the 1.4.0 Setup. Finish it
  from the Version card or from the tray icon's **Finish updating
  Domovoi...**. The Windows part adds the firewall rule the short address
  needs, for your home subnet only.
- **The scan reader arrives with the update.** The update installs
  Tesseract (`tesseract-ocr` and `tesseract-ocr-eng`) on Linux and Windows
  servers. With the internet set to No it can't: install those two
  packages by hand, or scans are read by the picture model alone (and not
  at all with AI features off). Until then, **What does it say?** doesn't
  show.
- **The short address on Linux.** The update gives the dashboard's unit the
  one permission it needs to use the low web port
  (`CAP_NET_BIND_SERVICE`, as the drop-in
  `domovoi-web.service.d/50-domovoi-short-address.conf`). A unit you
  manage yourself needs `AmbientCapabilities=CAP_NET_BIND_SERVICE` and the
  same in `CapabilityBoundingSet=`; until then the dashboard stays on
  6369 and Settings says the short address is off. If something else on
  the server uses that port, Domovoi leaves it alone.
  ([Details](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/docs/LINUX_HOST.md#sandboxing-the-units))
- **Friend Houses' firewall.** The update installs and starts
  `domovoi-fh-firewall.service`, whether or not Friend Houses is ever
  turned on. If you set `DOMOVOI_MANAGE_FH_FIREWALL=0`, fence the
  container's network yourself before turning Friend Houses on; the page
  warns until the rules are in place.
  ([The firewall](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/docs/LINUX_HOST.md#friend-houses-firewall))
- **Plugins:** a plugin that holds a websocket asks for SDK 1.11
  (`domovoi_api >=1.11`) and won't install on an older server, so update
  Domovoi first. The same holds for plugins that ask for SDK 1.9 or 1.10.
  Any other plugin websocket is still refused when the plugin loads.
- **Admins:** after the update, a signed-in dashboard tab stays admin for
  at most an hour unless someone changes something in it. **Stay signed in
  after a reload** set above 60 minutes now reads as 60.
- **Rooms:** **Upgrade** a room (its **Overview** tab) to let it run more
  than one wake word and to get the Wi-Fi and package fixes. A room on
  older software keeps working with its main word.
- **New rooms with the address left blank** ask only servers on this
  release. Update the server first, or type its address in the room's
  setup page.
- **A port-forward that changes the core's port** (outside 16370 to 6370,
  say) needs that `host:port` in `TRUSTED_HOSTS` for new rooms to check
  the server.
- **A printer on the server's own loopback,** added through
  `OUTBOUND_ALLOW_HOSTS`, now shows "isn't on the home network any more":
  remove it.
- **Scripts and other clients:** see the
  [API reference](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/docs/API_REFERENCE.md).
  The sign-in answers gain the idle fields, and there are new routes for
  queue history, scan reads, videos in chat, the short address, room wake
  words and Friend Houses. Nothing was removed.

## Known limits

- **Friend Houses:** one inbox for the whole house (Domovoi has no
  per-person sign-in), and encryption is between houses, not between
  people: the admins and software of both houses can read what is stored
  there. It needs the internet, and stops when the internet is set to No.
  A determined former friend could, over time, narrow down which Tor relay
  your house uses.
- **Scans are read in English only;** Domovoi has no household language
  setting yet.
- **One video or scan at a time,** at the lowest priority. On a server
  without a graphics card, expect a few minutes for a 3-minute clip.
- **More wake words, more false wakes.** Most homes need only one.
- **A new room with the address left blank** doesn't ask a server older
  than this release.
- **The USB stick for old computers is still a preview.**
- **The Windows installer and the Windows room Setup are not code-signed.**
  Windows SmartScreen will ask before running them.
- **No encryption on your home network.** Domovoi uses plain HTTP inside the
  house. It is not meant to be reachable from the internet, so do not
  port-forward its ports. The
  [security notes](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/docs/SECURITY_PRIVACY.md)
  say plainly what it does and does not guard.

## Verifying a release

Every file here is listed in `SHA256SUMS`, the Windows Setup is signed with
Domovoi's release key, and each file has GitHub build provenance, recorded
by the same release run that signed it. With the
[GitHub CLI](https://cli.github.com/):

```bash
gh attestation verify DomovoiSetup.exe -R coders-farm-official/domovoi
```

[SECURITY.md, Verifying a release](https://github.com/coders-farm-official/domovoi/blob/v1.4.0/SECURITY.md#verifying-a-release)
has the details.
