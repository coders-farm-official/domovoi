# Domovoi 1.4.1

**The home computer system that just works. Keeps it in the house.**

Domovoi turns a computer you already own into your home's own system: your
music, movies, audiobooks, files and documents in one place, playing in every
room and on your phone. No cloud, no subscription, and nothing leaves your
network unless you say so.

This release follows 1.4.0 and is a fix release. Chat finds answers on the
web when the offline library has nothing on the question, weather answers
are back for a new Home location, music no longer goes silent after a
question, Friend Houses opens to the whole household, and "print this"
works on a picture or file in a chat. It also carries many tighter checks
and limits from a round of security work. The Android app 1.4.1 comes with
it. If this is your first look, start with the
[README](https://github.com/coders-farm-official/domovoi#readme).

## Highlights

- Friend Houses is open to everyone in the household, by voice too.
- Voice ID learns better from short samples.
- Music keeps playing after you ask a question.

## At a glance

- **Chat looks on the web when it needs to:** with the internet allowed, a question the offline library can't answer goes to web search, and sources that don't fit the question are left out. ([Manual](https://github.com/coders-farm-official/domovoi/blob/v1.4.1/scripts/manual/manual.md#look-things-up))
- **Weather answers are back,** for your town, set once in Settings → Household → **Home location**; holiday questions ("how many days until Thanksgiving") are answered offline. ([Manual](https://github.com/coders-farm-official/domovoi/blob/v1.4.1/scripts/manual/manual.md#quick-answers))
- **Music keeps playing after a question:** every voice turn brings the room's music back, and a room that can't play says "paused" instead of "playing". ([Manual](https://github.com/coders-farm-official/domovoi/blob/v1.4.1/scripts/manual/manual.md#music-and-room-queues))
- **Friend Houses for the whole household:** messages and shared lists on the dashboard and the phone for everyone, "send the Bassetts a message saying …" by voice, and messages held for quiet hours said when they end. ([Manual](https://github.com/coders-farm-official/domovoi/blob/v1.4.1/scripts/manual/manual.md#talk-to-other-rooms))
- **A chime before announcements and broadcasts,** so people catch the first words; yes/no questions now sound like questions. ([Manual](https://github.com/coders-farm-official/domovoi/blob/v1.4.1/scripts/manual/manual.md#talk-to-other-rooms))
- **"Print this" on a picture or file in a chat** opens the Print dialog on it. ([Manual](https://github.com/coders-farm-official/domovoi/blob/v1.4.1/scripts/manual/manual.md#printers-and-scanners))
- **Voice ID learns better from short samples:** "my name is …" replaces a short room sample, and only that person can answer "Was that you?". ([Manual](https://github.com/coders-farm-official/domovoi/blob/v1.4.1/scripts/manual/manual.md#people-and-voices))
- **Microphone presets for XVF3800 rooms:** an admin can try presets for noisy rooms from the room's Settings tab. ([Satellite hardware](https://github.com/coders-farm-official/domovoi/blob/v1.4.1/docs/SATELLITE_HARDWARE.md#the-two-supported-mic-boards))

**After updating:** press **Upgrade satellite** on each room (the satellite code changed), and update the Android app to 1.4.1.

### Also in this release

- **The dashboard:** a new plugin's page appears in every open tab without a reload, every confirmation is a dialog inside the page, the Version card shows the new version after a restart, and Settings search finds every setting.
- **Spoken questions go first:** a bedtime story, a memory pass or a news briefing waits while a room answers, and bigger servers answer more than one AI request at once.
- **A busy machine no longer restarts the core,** and a plugin that loads slowly on a busy start stays on.
- **Downloads in Files** are the browser's own download, with its progress, and a paired phone or browser can download a whole folder.
- **Updates remove more packages** Domovoi no longer uses.

### Security fixes

- **Tighter checks on sign-in and admin actions:** changing the admin password, recording wake-word clips and a room's satellite settings.
- **Tighter checks on rooms and satellites:** pairing, approvals, room names, what a device reports when it connects, and how a room checks its server.
- **Tighter checks on Friend Houses:** limits on connections, requests and pings, wake words kept out of what is read aloud, and sign-in again after an admin reset.
- **Tighter limits on outside reads:** feeds, pages, downloads, printer discovery, video and scan helpers, and plugin installs from GitHub.
- **The dashboard's live connections** end soon after a sign-out or a new household key.
- **Package updates:** the Documents editor's Tiptap 3.33.1 (an accepted advisory fixed) and the wake-word trainer image on torch 2.14.1 with no open advisories.

### Upgrading

- **Update as usual:** Settings → System → About & updates → **Update Domovoi**. The one database change runs by itself. Windows: finish the Windows part from the Version card or the tray icon.
- **Rooms:** **Upgrade satellite** on each room's Overview tab.
- **Phones:** update the Android app to 1.4.1 for Friend Houses on the phone and printing from a chat.
- **Home location:** pick your town in Settings → Household if the field asks you to.
- **Plugin authors:** SDK 1.12 and 1.13 are new; update Domovoi before installing a plugin that asks for them.

### Known limits

- **Microphone presets are not saved** to the XVF3800: they last while the room runs.
- **Holidays offline** cover the US, Canada, the UK, Ireland, Australia and New Zealand.
- **The Windows Setups are not code-signed,** and Domovoi uses plain HTTP inside the house: don't open its ports to the internet.
- **The Mac package is signed ad hoc,** not by an identified developer, and runs on Apple silicon Macs only.

## What is new since 1.4.0

### Chat, lookups and weather

- **Chat reaches the web** when the offline library has nothing relevant.
  Before, the library's first results filled every slot, related or not,
  and the reply was "I couldn't find that in what I looked up."
- **Every source is checked for relevance** before it is read or cited,
  and a reply that couldn't find the answer lists no sources.
- **Local questions go to the web first:** businesses, opening hours,
  "near me", news, weather and prices. With the internet set to "never",
  such a question gets "I need the internet for that". If the first lookup
  doesn't answer, the chat tries once more on the web, and a short
  follow-up like "how about now?" repeats the lookup.
- **The chat's internet chip** says "internet: ask first" when Domovoi asks
  before going online.
- **Home location:** Settings → Household → **Home location** is one field
  where you start typing and pick your town from a list that comes with
  Domovoi, so what you type never leaves the house. Weather and local news
  use it. It replaces Local news location, and what you had there is
  carried over once.
- **Weather:** "What's the weather today?" answers with the current
  temperature and conditions for the Home location, from Open-Meteo, or
  wttr.in when Open-Meteo has no answer.
- **Holidays offline:** "how many days until New Year's Day", "when is
  Thanksgiving", "what day is Easter next year".

### Voice

- **A chime before announcements and broadcasts** ("tell the kitchen dinner
  is ready", Broadcast, timers, reminders and plugin announcements), on
  every kind of room with no update on the room. Normal answers never get
  it. Settings, Voice & speech, **Chime before announcements** turns it
  off.
- **Yes/no questions sound like questions:** "That's 2 pages to the office
  printer. Should I print it?"
- **"Should I remember that?"** comes after a remark or a chat, at most once
  a day per person, never for something Domovoi already knows, and a
  one-word "yes" saves the fact.
- **Suggestions use remembered tastes again** for someone Domovoi
  recognizes, and a food suggestion adds a line when someone in the house
  has a remembered allergy or diet, naming no one.
- **Spoken questions go first** with the house's AI model, and servers with
  24 GB of memory or more answer more than one request at once.
- **Voice ID:** saying "my name is …" again replaces a short room sample;
  a room with only short samples of you also uses your samples from other
  rooms; and "Was that you?" can only be answered by that person. Say
  "yes, that was me" rather than a bare "yes".

### Friend Houses

- **Open to everyone in the household:** Messages and Shared lists need
  only the household's paired browser or phone; making friends, requests
  and blocking stay with the admin, under **Friends and connections**. The
  page now starts with Messages.
- **By voice:** "send the Bassetts a message saying …", "text the
  Bassetts …", "let the Bassetts know that …" and "ask the Bassetts …", read
  back before it is sent.
- **Quiet hours:** a friend set to be read aloud shows when new messages
  will be said, and messages held for quiet hours are said in each room
  when its quiet hours end, if still unread. Messages that arrive within a
  minute of each other are said together.
- **Removing or blocking a friend stops sharing lists** with that house;
  each house keeps its own copy as an ordinary list.
- Home's "needs attention" counts unread Friend Houses messages.

### Music, radio and podcasts

- **Music comes back after every question,** including a turn the room
  drops. A room whose satellite can't play the stream says "paused", and
  "play" starts its player again. This needs the satellite update.
- **Up next keeps the songs a jump passed** on a long room queue.
- **A guest can't start a stopped room** with "play this one".
- **Radio 1.5.1 to 1.5.3:** plainer wording about song identification, and
  station streams and now-playing polls read within tighter limits.

### Files, documents, printing and video

- **Downloads are the browser's own:** a one-use link that lasts a minute,
  a folder's zip streamed as it is built, and a whole folder (up to 5000
  files) for a paired phone or browser.
- **"Print this"** on a picture or document attached to a chat opens the
  Print dialog on it. The phone apps show this card once they update.
- **The Documents editor runs on Tiptap 3,** with documents, saving and
  co-editing as before.
- **A chat draft's changes view** leaves a gap between removed and added
  text.
- Word copies, the sheet editor and video poster frames run off the
  dashboard's main work.

### Rooms and satellites

- **Microphone presets for XVF3800 satellites:** signed in as admin, the
  room's Settings tab has a **Microphone DSP** block with the factory
  settings or presets B, C and D for noisy rooms, the values the array read
  back, and a **Mark** field that stamps a note into the logs.
- **A room set up for a different server** is listed under Settings → Rooms
  with the advice to set it up again for this one.
- **A room paired under an older id** (capitals, spaces) can now be removed
  from the dashboard.
- **Resetting a room's pairing, or removing it,** closes its satellite's
  connection.

### The dashboard and plugins

- **A new plugin's page shows up** in every open tab without a restart or
  reload.
- **Confirmations are dialogs inside the page,** so "Update Domovoi" works
  in embedded browsers that dropped the browser's own pop-ups.
- **The Version card** reads the server again after a restart, and a
  restart no longer asks every tab to reload for plugins that didn't
  change.
- **Settings search** looks at each setting's group, help text and other
  names it is known by.
- **A slow start no longer switches a plugin off:** it shows "loaded
  slowly" instead.
- **A refused plugin install names each clashing package** and what the
  plugin wanted.
- **Plugin SDK 1.12 and 1.13:** the Home location for plugins, a weather
  plugin takes weather questions over, and raw stream reads (1.13.1).

### The server and updates

- **A busy machine no longer restarts the core:** a slow database answer
  is asked again on a separate connection before it counts.
- **Updates remove more packages** Domovoi stopped using, on Linux, Windows
  and Mac servers set up before 2026-10-15.
- **The wake-word trainer image** moves to torch 2.14 (a one-time rebuild,
  about 4 GB, on servers with training turned on).
- **The phone app's speech-recognition libraries** are rebuilt in CI and
  must match their committed checksums.

## Security fixes

This release carries tighter checks and limits from a round of security
work. None needs anything from you beyond updating and upgrading each room.

- **Sign-in and admin:** changing the admin password waits after a wrong old
  password, like the sign-in form; recording wake-word clips and changing a
  room's satellite settings need an admin; Friend Houses waits for an admin
  after an admin reset.
- **Live connections:** the dashboard's live-state and co-editing
  connections check their sign-in again and end soon after a sign-out or a
  new household key; WebSocket messages have a smaller size cap.
- **Rooms and satellites:** stricter room ids and room names, stricter
  checks on approvals and pairing, bounded first messages from devices, and
  limits on how a room reads and checks its server's answers.
- **Friend Houses:** limits on connections, requests and retries, safer
  writes of its own files, IPv6 dropped by its firewall, and friends' text
  kept out of the chat model's history.
- **Outside reads:** whole-answer deadlines and size caps for feeds, pages
  and downloads, one supported compression at most, bounded printer
  discovery, and limits on the helper programs behind videos and scans.
- **Plugins:** installs from GitHub only from GitHub's own addresses, with
  well-formed branch and tag names; plugin errors shown to an admin only.
- **Household data:** download-queue rows, podcast feed addresses and
  playback positions, and a person's voice samples list show less to
  callers without a household or admin credential; phone and browser
  listens have a house-wide daily cap.
- **Windows updates:** the downloaded Setup is copied more strictly.
- **Packages:** Tiptap 3.33.1 for the Documents editor, and every package in
  the wake-word trainer image at a version with no open advisory.

## Upgrading

- **Linux servers:** Settings → System → About & updates → **Update
  Domovoi**. The one database change (V072, an index for the listens cap)
  runs by itself, and the update rolls back by itself if the new code does
  not come up healthy.
- **Windows installs:** the same **Update Domovoi** on the Version card; it
  updates both halves, or finish the Windows part from the tray's **Finish
  updating Domovoi...**.
- **Once, during the update:** the AI model service and the bundled search
  service restart, and a server with wake-word training on rebuilds the
  trainer image (about 4 GB more to download).
- **Rooms:** Settings → Household → Rooms → the room's **Overview** tab →
  **Upgrade satellite**, on every room. It brings the satellite's own
  checks, music that is reported when it won't play, and on an XVF3800 the
  Microphone DSP block. A room on older software keeps working.
- **Home location:** if your old Local news location named more than one
  town, Settings → Household → **Home location** asks you to pick yours.
  With none set, set one to get a local weather answer.
- **Android:** update to 1.4.1 from Google Play or your server's
  **Download the app to this server**. Older apps keep working.
- **Plugin authors:** compile a plugin's lock with
  `pip-compile -c requirements-linux-py314.lock`, and see
  [PLUGIN_DEVELOPMENT.md](https://github.com/coders-farm-official/domovoi/blob/v1.4.1/docs/PLUGIN_DEVELOPMENT.md)
  for SDK 1.12 and 1.13.

## Known limits

- **Microphone presets** are runtime only: nothing is saved to the array.
- **The offline holiday table** covers the common public holidays of the US,
  Canada, the UK, Ireland, Australia and New Zealand, plus Easter and the
  days counted from it.
- **Weather needs the internet,** and Open-Meteo is free for personal,
  non-commercial use.
- **The Windows Setups are not code-signed.** Windows SmartScreen will ask
  before running them.
- **No encryption on your home network.** Domovoi uses plain HTTP inside the
  house. It is not meant to be reachable from the internet, so do not
  port-forward its ports. The
  [security notes](https://github.com/coders-farm-official/domovoi/blob/v1.4.1/docs/SECURITY_PRIVACY.md)
  say plainly what it does and does not guard.

## Verifying a release

Every file here is listed in `SHA256SUMS`, the Windows Setup is signed with
Domovoi's release key, and each file has GitHub build provenance, recorded
by the same release run that signed it. With the
[GitHub CLI](https://cli.github.com/):

```bash
gh attestation verify DomovoiSetup.exe -R coders-farm-official/domovoi --signer-workflow coders-farm-official/domovoi/.github/workflows/release.yml --source-ref refs/heads/main
```

It passes only for a file with exactly those bytes, attested by the
release workflow run from `main`.

[SECURITY.md, Verifying a release](https://github.com/coders-farm-official/domovoi/blob/v1.4.1/SECURITY.md#verifying-a-release)
has the details.
