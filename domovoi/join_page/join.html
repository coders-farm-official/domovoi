Get the Domovoi app

The Domovoi app for this home's Android phones and tablets (Android 8 or newer), straight from this home's own Domovoi server.

This page is for Android phones and tablets. A laptop or PC becomes a room with the install command on the dashboard (Settings → Rooms → add a spare device); iPhones and iPads can't be rooms yet.

The room code in this link can't be read. Make a new code on the dashboard and scan it again.

The Domovoi app isn't on this phone yet. Install it first (step 1), then press the button in step 2 again.

  1. 1 Install the app

    asking this server about the app…
    download the app

    Didn't start, or did your phone block it?

    The phone blocked it? What to tap
    • “This file might be harmful” or “can’t be downloaded securely” (Chrome): tap Download anyway or Keep. Or open the browser’s Downloads list and tap the file.
    • “Download multiple files?” (Chrome): tap Allow, then press Try again.
    • “For your security, your phone isn’t allowed to install unknown apps from this source”: tap Settings, turn on Allow from this source, then go back.
    • Play Protect “blocked” or “unsafe app”: tap More details, then Install anyway.
    • The install screen never appeared? Open the Downloads app (or Files) on the phone and tap the Domovoi file.

    Another browser works too (Firefox, Samsung Internet, Edge): copy this link and open it there.

    If the phone says App not installed, download the other one. Domovoi .

    The Domovoi app already on this phone? Go on to step 2.

    Installing it, the first time

    The words differ a little from phone to phone.

  2. 2 Open it as

    open as this room

    The app opens Domovoi Room with this room's code filled in. Read its explanation to the end, allow the microphone and press Become this room. The phone then shows a six-digit code: whoever runs Domovoi types it on the dashboard, and the phone is a room.

    Nothing happens? Open Domovoi Room from the home screen and scan the code on the dashboard with it.

  3. 2 Open Domovoi

    Open the app and pick this home's Domovoi from the list it finds on your Wi-Fi.
